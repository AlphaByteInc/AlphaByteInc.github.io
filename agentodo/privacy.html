プライバシーポリシー

AgenTodo（iPhone / iPad / Mac アプリ）

株式会社アルファバイト（以下「当社」）は、アプリ「AgenTodo」（iPhone / iPad 版、Mac 版、Mac で動く常駐プログラム「runner」、MCP サーバーを含みます。以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

要点
  • ToDo・メモ・添付ファイル・AI への依頼と結果は、利用者のアカウントにひも付けて当社が契約するクラウド（Supabase、東京リージョン）に保存し、利用者の端末どうしで同期します。
  • 音声認識と、音声やカレンダー・メールから ToDo の候補を作る AI の処理は、端末の中（Apple の端末内のモデル）だけで行います。音声や AI に渡した文を当社に送ることはありません。
  • カレンダーの予定と Gmail のメールは端末の中で読み、当社のサーバーには送りません。
  • 広告、アクセス解析、トラッキング、他社のクラッシュ解析ツールはありません。本アプリは無料で、アプリ内課金もありません。
  • アプリの中から、いつでもアカウントとサーバー上のすべてのデータを削除できます。

1. 当社のサーバーに保存する情報

本アプリはアカウント制です。同期と AI への依頼のために、次の情報を利用者のアカウントにひも付けて保存します。

アカウントの情報

  • メールアドレス、利用者を識別する ID、ログイン方法（Apple でサインイン / Google でサインイン / メールアドレスとパスワード）。パスワードはハッシュ化して保存し、当社は元のパスワードを知ることができません。
  • Apple でサインインでメールを非公開にした場合は、Apple が発行する転送用のアドレスを保存します。Google でサインインの場合は、Google から受け取るメールアドレスと表示名を保存します。

利用者が入力・作成した内容

  • ToDo（タイトル、メモ、期限、優先度、タグ、リスト、並び順、完了状態）とフリーノート
  • ToDo に付けた写真・ファイル（1件50MBまで）
  • AI エージェントへの依頼、その進み具合・ログ・結果、ToDo ごとの会話（スレッド）
  • 自動振り分けのルール、送り先とモデルの既定などの設定
  • 利用者が登録した Webhook の送り先 URL と送信キー（送信キーは暗号化して保存します）、受け口の Webhook で受け取った文や音声ファイル

接続したパソコンと AI の情報

  • Mac 版や runner を入れたパソコンの表示名、ホスト名、OS とモデル名、アプリと runner のバージョン、最後に接続した日時
  • そのパソコンで使える AI（Claude Code / Codex / Gemini / Cursor など）の有無、バージョン、ログイン中のアカウントの表示（メールアドレスやプラン名）、利用量の目安（使用率、トークン数、費用の見積もり）
  • MCP で接続したツールの名前、権限、アクセスの記録（日時、呼び出したツール、IP アドレス、User-Agent）。不正な利用を見つけて止めるために使います。

ロック画面の表示（ライブアクティビティ）のための情報

  • ライブアクティビティを使う場合、端末を区別する ID と、Apple のプッシュ通知サービス（APNs）が発行するトークンを保存します。アプリを閉じていても依頼の進み具合をロック画面に出すために使います。設定でオフにできます。

その他

  • iPhone と Mac をつなぐときの使い捨てのコードと、失敗した試行の IP アドレス（総当たりを防ぐため。短期間で消します）

2. 端末の中だけで扱う情報

  • 音声: マイクの音声は、端末の音声認識（端末内で処理するモード）で文字にします。録音は音声入力の画面を開いている間だけで、音声そのものは保存も送信もしません。文字にした結果は、利用者が ToDo やノートとして保存したときだけサーバーに保存されます。
  • 端末内の AI: 話した内容の整理、ToDo の振り分け、状況の要約、ToDo の候補づくりには、Apple の端末内のモデル（Apple Intelligence の Foundation Models）を使います。処理は端末の中で完結し、当社や他社の AI サービスに送りません。
  • カレンダー: 許可した場合、今日から7日先までの予定を端末の中で読んで候補を作り、期限のある ToDo を予定として書き込みます。予定の内容を当社のサーバーに送りません。
  • Gmail: 利用者が連携した場合だけ、Google から読み取り専用の許可（gmail.readonly）を受け、端末から直接 Google に接続して受信メールの件名と冒頭を読み、端末内の AI で候補を作ります。メールの本文を当社のサーバーに送ったり保存したりしません。Google の認証情報は端末のキーチェーンにだけ保存します。連携はいつでも外せます。本アプリによる Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • カメラ・写真・ファイル: 撮った写真や選んだファイルは、利用者が ToDo に添付したときだけアップロードします。カメラは Mac をつなぐときの QR コードの読み取りにも使います。
  • ショートカットで渡したメモ: 端末の中にだけ置き、候補づくりに使います。

3. 利用目的

  • ToDo・ノート・添付ファイルを保存し、利用者の端末やウィジェット、Mac 版と同期するため
  • 利用者が選んだ AI エージェントに依頼を届け、結果を表示するため
  • ロック画面やダイナミックアイランドに依頼の進み具合を表示するため
  • 不正なアクセスを防ぎ、サービスの安全を保つため
  • お問い合わせに回答するため

当社は、これらの情報を広告、利用者の行動の追跡、プロファイリング、AI モデルの学習には使いません。

5. 利用者が自分でつなぐ AI と送り先

本アプリは、利用者が自分で選んでつないだ AI や送り先に、依頼の内容（ToDo のタイトル、メモ、追加の指示、会話）を渡します。これらは利用者の指示による送信であり、送った先での取り扱いはそれぞれの提供元の規約とプライバシーポリシーによります。

  • 利用者の Mac の AI: Mac 版と runner は、利用者の Mac に入っている Claude Code（Anthropic）、Codex（OpenAI）、Gemini CLI（Google）、Cursor などを、利用者自身のアカウントで動かします。依頼の内容は、その AI の提供元に利用者のアカウントで送られます。当社がこれらの提供元と契約して情報を渡すものではありません。
  • Webhook の送り先: 利用者が設定した URL（Grok Bot、Muse など）に、依頼と ToDo の内容を送ります。
  • MCP: 利用者が接続を作った AI ツールは、許可した範囲で利用者の ToDo を読み書きできます。接続はいつでも取り消せます。

6. 第三者への提供

当社は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。第4項の外部サービスには、本アプリの提供に必要な範囲で取り扱いを委託しています。広告配信、アクセス解析、トラッキングのための SDK は組み込んでいません。

7. 安全管理

通信はすべて暗号化（HTTPS）します。データベースは行単位のアクセス制御で、利用者本人だけが自分のデータを読み書きできるようにしています。Webhook の送信キーは暗号化して保存し、端末のログイン情報や Google の認証情報は端末のキーチェーンに保存します。

8. 保存期間と削除

サーバーの情報は、アカウントを削除するまで保存します。ToDo やノートを削除すると、同期のための削除の記録を最大30日残したうえで消します。

アカウントの削除: アプリの右上の「…」>「アカウント」>「アカウントを削除」から、いつでも削除できます。削除すると、アカウントと、サーバー上のすべてのデータ（ToDo、ノート、添付ファイル、依頼と結果、会話、接続したパソコン、MCP の接続、Webhook の設定、ライブアクティビティのトークン、アクセスの記録）を削除し、元に戻せません。アプリから削除できない場合は、第11項の窓口にご連絡ください。

端末の中の情報（設定、候補、キーチェーンのログイン情報など）は、アプリを削除すると消えます。本アプリが書き込んだカレンダーの予定は、設定の「連携」>「カレンダー」で連携をオフにすると削除されます。
